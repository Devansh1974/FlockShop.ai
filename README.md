# 🛍️ FlockShop.ai - Collaborative Shared Wishlist App

Welcome to the **FlockShop.ai Internship Assignment** submission. This project demonstrates a real-world, full-stack implementation of a **Collaborative Wishlist App**, where users can create, manage, and interact with shared shopping wishlists.

---

## 📌 Project Objective

To build a **shared wishlist platform** that supports:

- User Authentication (mocked)
- Wishlist creation, editing, deletion
- Product management within wishlists
- Real-time collaboration (future scope)
- A clean, responsive, modern UI/UX

---

## 🛠️ Tech Stack

| Layer       | Technology                     |
|------------|--------------------------------|
| Frontend   | React + Vite + Tailwind CSS    |
| Backend    | Node.js + Express              |
| Database   | MongoDB + Mongoose             |
| Styling    | Tailwind UI + Headless UI      |
| Icons      | Heroicons                      |
| API Tool   | Bruno/Postman (for testing)    |

---

## 🚀 Setup Instructions

> Follow these steps to run the app locally on your machine.

### ⚙️ Backend Setup

1. **Clone the Repository**  
   ```bash
   git clone https://github.com/your-username/flockshop-wishlist.git
   cd backend

2. **Install Dependencies**
    ```
    npm install

    ```

3. **Configure Environment**

```
MONGO_URI='add your own string'
PORT=5000

```

4. **Start Backend Server**
```
npm run dev
```
